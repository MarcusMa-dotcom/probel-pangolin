Connection

Connects to the SW-P-08 port of a router or router controller, or to the Router tab of this program. The port is set at the router, 8910 is a common choice. The first row of switches says what is read right after connecting. Automatic uses the extended commands when the router reports them or the numbers need them. Attempts is how often a message is sent until the router acknowledges it. The specification recommends 5, with one second each.

SW-P-02 is the older General Switcher protocol, usually on TCP port 2000: one level, no matrix number, no names and no ACK. A take is confirmed by the CONNECTED of the router. There is no tally dump either, so "Read all crosspoints" asks the first destinations one by one, as many as set here.

        Virtual router

        A router made of software, for controllers under test. 0.0.0.0 listens on all network interfaces, 127.0.0.1 only on this machine. SW-P-08 has no login: whoever reaches the port can switch. Changing protocol, size, address or command set restarts a running router. As an SW-P-02 router it has one level, up to 1023 sources and 1024 destinations, and never answers with NAK.

                OffsetBytesMeaningFrame check

                Takes the bytes of a serial sniffer, a hex stream copied from Wireshark, or a trace of this program. Both directions may be mixed. It finds every frame, checks byte count and checksum, undoes the doubled DLE and says what the message means. An ACK in the middle of a frame is allowed and listed on its own.
